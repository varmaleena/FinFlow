# Three-minute demo

1. Start as **Ramesh Kirana**, reset the demo, and select **Missing confirmation**. Observe rail/provider success but missing acknowledgement. Open the evidence panel.
2. Select **Retry notification safely**. The local simulator delivers acknowledgement, verification changes the case to RESOLVED, and the audit trail records policy, execution and verification. Download the audit JSON if useful.
3. Choose **Settlement breakdown**. Gross ₹28,450 minus refunds ₹1,200, fees ₹142.25 and adjustments ₹500 equals the credited ₹26,607.75.
4. Open **Credit studio**. Adjust amount, term and annual rate; observe recalculated EMI, interest and total repayment. Point out the excluded fees and no-approval disclaimer.
5. Select **Pending payment**, then **Monitor payment**. The app warns against duplicate collection. Two checks at 15-second worker intervals lead to a durable escalation. The time until the first check depends on the worker cycle.
6. Change merchant to **Anita Fashions**, select her transaction to demonstrate conflicting evidence. Explain her settlement to show an unexplained ₹1,290 mismatch and escalation.

Optional voice: select English/Hindi and use the microphone. Browser dictation needs a compatible browser; Sarvam needs a key. Inspect the transcript before sending. Use Listen to hear the response.
